# Single Page Application

Site pour une agence de freelances tiré du cours [OpenClassrooms](https://openclassrooms.com/fr/courses/7150606-creez-une-application-react-complete)


## Compétences ciblées

- Installation et configuration de Prettier et ESLint
- React Router
- CSS in JS avec styled components
- Calls API avec useEffect et useState
- Partage du state avec useContext
- Rédaction de test avec vitest et React Testing Library
- Anciennes syntaxes de React : _class_ et _appel API dans un composant class_
